# Partledger (working name)

A parts-and-suppliers platform for small and mid-sized manufacturers. Every part, its approved suppliers, their quotes and the proof behind them live in one place: synced from the ERP, read by AI, and locked into award records auditors can trust. A compliance pack per market decides which proof each part needs.

Status: pre-planning. Start with [docs/brief.md](docs/brief.md); implementation plans go in `docs/plans/`.
